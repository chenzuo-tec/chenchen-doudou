# 晨晨 × 豆豆 · 恋爱纪念书

零依赖 HTML / CSS / JavaScript 网站，适合 GitHub Pages。无收费 API、外部字体、跟踪脚本或后台。

## 功能

- 四个独立页面：首页 `index.html`、恋爱日历 `anniversaries.html`、愿望 `wishes.html`、抽卡 `cupid.html`。
- 恋爱日期固定为 **2026 年 5 月 15 日**，按北京时间计算日历天数；月 / 半年 / 周年纪念日，支持自选特别日子。
- 等宽双开书本：正面对称布局，书脊居中，左右页向两侧张开。默认轻微倾斜，保持文字可读，保留封皮厚度和书底投影；可切换平视阅读，手机横向滑动阅读双页。
- 电脑端依据实际浏览器宽高自动适配一屏，页面及书页内部均无上下滚动。各章节采用紧凑排版，愿望、奖励池和奖励记录每页展示三项，使用页内箭头查看后续内容。
- 切换章节先加载下一页，然后让带正反两面内容的完整书页围绕书脊旋转 180°，露出下面的下一页。动画完整结束后才跳转，避免截断翻页。
- 打开和切换章节会从书缝飞出 26～30 只蝴蝶，带独立振翅和飞行轨迹。系统减少动态效果时自动关闭飞行动画。
- 可翻月的纸质日历、纪念日标记、漂浮爱心和翻卡动效；支持系统减少动态效果设置。
- 愿望新增、完成、删除，JSON 导出 / 导入分享。
- 4×4 共十六张丘比特卡片，按主人发布的配置抽取，等概率，可重复奖励；用完后重新开始。访客没有奖励 / 次数编辑入口。
- 桌面丘比特爱心箭光标，手机触摸抽卡；刷新保留进度。

所有数据只保存在当前浏览器的 localStorage，不会自动同步到另一台设备。清除浏览器数据会清除设置。愿望清单导入会替换现有清单。小游戏是娱乐用途，没有现金支付、账号或实际奖励兑现。

## 本地查看

在本目录运行 `node preview-server.mjs`，然后访问 http://127.0.0.1:8000 。也可使用任何静态 HTTP 服务。使用 JavaScript 模块，因此不要直接双击 HTML 以 file:// 打开。

## 免费发布到 GitHub Pages

1. 登录自己的 GitHub 免费账号，创建一个公开仓库，比如 `chenchen-doudou`。
2. 将四个 `.html` 页面、`style.css`、`app.js`、`core.js`、`game-config.json`、`.nojekyll` 上传到仓库根目录。
3. 进入仓库 **Settings → Pages**，在 **Build and deployment** 中选 **Deploy from a branch**。
4. 选择 `main` 分支、`/ (root)` 文件夹并保存。
5. 等待部署完成，访问 Pages 页面返回的网址，格式为 `https://你的用户名.github.io/chenchen-doudou/`。

无需购买域名，使用平台提供的网址。GitHub 免费公开仓库中的代码及上传文件对外可见。实际网址以 GitHub 返回值为准。

已发布网址：https://chenzuo-tec.github.io/chenchen-doudou/ 。恋爱日期和奖励规则对所有设备一致；愿望、倒计时偏好及抽卡进度保存在各自浏览器。旧版日期自动替换为 5 月 15 日，愿望保留；旧版自定义奖励和机会数不再读取，新规则会重新开始一轮。

## 主人修改奖励和机会数

用你的 GitHub 账号打开仓库里的 `game-config.json`，修改后提交到 `main`，GitHub Pages 会自动发布：

- `chances`：每轮机会数，1～16 的整数，当前仍为 3 次。
- `rewards`：1～50 个奖励字符串，每个不超过 120 字。
- `revision`：更新标识；修改为新的文字，会让访客下次打开时重置当前抽卡轮次。奖励或次数变化也会自动重置。

只有拥有仓库写入权限的 GitHub 账号可以修改正式发布的规则；请保持仓库由你单独管理。公开访客能查看配置，但无法直接写入你的仓库。访客的旧 localStorage 奖励与次数会被忽略。此方式保护的是线上发布配置，并非防作弊：静态站无法阻止访客通过开发者工具修改自己的页面、清除进度或重复抽奖。若要严格限制个人次数或使用网页管理员登录，需另加带身份验证的后台。

## 检查

`npm run check` 检查语法，`npm test` 验证日期边界和抽卡机会限制。无需 npm install。
